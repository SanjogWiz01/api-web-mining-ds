Topic 01 · Foundation

🌐 HTTP Basics

HTTP (HyperText Transfer Protocol) is the backbone of all web communication. Every API call is an HTTP request. Master these four methods and you've mastered the foundation.

GET

Read / Retrieve

Fetch data from the server. Safe and idempotent — calling it 100 times has the same effect as calling it once.

GET /posts/1 200 OK
POST

Create New Resource

Send data to create a new resource. Not idempotent — each call creates a new record.

POST /posts 201 Created
PUT

Update / Replace

Replace an entire resource. Idempotent — the resource ends up in the same state regardless of repetition.

PUT /posts/1 200 OK
DELETE

Remove Resource

Delete a resource permanently. Idempotent — deleting something that's already deleted is still a success.

DELETE /posts/1 200 OK
Python · 01_http_basics.py 
import requests

BASE_URL = "https://jsonplaceholder.typicode.com"

# ── GET: Retrieve posts ───────────────────────
def demo_get():
    response = requests.get(f"{BASE_URL}/posts", params={"_limit": 3})
    print(f"Status: {response.status_code}")      # → 200
    print(f"URL: {response.url}")               # Full URL with params
    posts = response.json()
    for post in posts:
        print(f"  [{post['id']}] {post['title'][:60]}...")

# ── POST: Create a post ───────────────────────
def demo_post():
    payload = {"title": "Understanding HTTP Methods",
               "body": "GET retrieves, POST creates...", "userId": 1}
    response = requests.post(f"{BASE_URL}/posts", json=payload)
    print(f"Status: {response.status_code}")      # → 201
    created = response.json()
    print(f"Created ID: {created.get('id')}")

# ── PUT: Full update ──────────────────────────
def demo_put():
    updated = {"id": 1, "title": "Updated Title via PUT",
               "body": "Replaces the entire resource.", "userId": 1}
    response = requests.put(f"{BASE_URL}/posts/1", json=updated)
    print(f"Status: {response.status_code}")      # → 200

# ── DELETE: Remove resource ───────────────────
def demo_delete():
    response = requests.delete(f"{BASE_URL}/posts/1")
    print(f"Status: {response.status_code}")      # → 200

Topic 02 · Security

🔐 Authentication

Most production APIs require authentication. You need to prove who you are before accessing data. There are four major auth patterns you'll encounter.

API Key Authentication

The simplest form. A unique key issued by the API provider. Can be passed via query parameter (less secure) or request header (recommended).

✅ Pros

  • Simple to implement
  • Stateless
  • Easy to rotate

⚠️ Cons

  • Long-lived if not rotated
  • No per-user scoping
  • Risks if leaked
Python
# ✅ Method 1: API Key in Header (recommended)
headers = {
    "X-API-Key": os.environ.get("MY_API_KEY"),  # From env, never hardcoded!
    "Content-Type": "application/json",
}
response = requests.get("https://api.example.com/data", headers=headers)

# ⚠️ Method 2: API Key in Query Param (less secure)
params = {"api_key": os.environ.get("MY_API_KEY")}
response = requests.get("https://api.example.com/data", params=params)
# Key appears in URL — visible in logs, browser history!

Bearer Token (JWT / OAuth2 Access Token)

The most common modern auth. A signed token (usually JWT) is sent in the Authorization header. The server validates the token without a database lookup.

✅ Pros

  • Stateless, scalable
  • Contains user claims
  • Short-lived (expires)

⚠️ Cons

  • Can't be invalidated before expiry
  • Larger payload than session ID
Python
TOKEN = os.environ.get("ACCESS_TOKEN")  # JWT or opaque token

headers = {
    "Authorization": f"Bearer {TOKEN}",   # Always "Bearer " prefix
    "Content-Type": "application/json",
}
response = requests.get("https://api.github.com/user/repos", headers=headers)
response.raise_for_status()          # Raises on 401 Unauthorized
repos = response.json()

# Using a persistent Session (efficient for multiple calls)
session = requests.Session()
session.headers.update({"Authorization": f"Bearer {TOKEN}"})
repos = session.get("https://api.github.com/user/repos").json()

Basic Authentication

Username + password encoded in Base64 and sent in the Authorization header. Legacy pattern — only use over HTTPS, and prefer API keys where possible.

✅ Pros

  • Universally supported
  • Simple implementation

⚠️ Cons

  • Credentials on every request
  • Base64 is NOT encryption
  • Requires HTTPS
Python
from requests.auth import HTTPBasicAuth
import base64

# Method 1: requests handles encoding automatically ✅
response = requests.get(
    "https://api.example.com/data",
    auth=HTTPBasicAuth("username", "password")
)

# Method 2: Shorthand tuple syntax
response = requests.get(url, auth=("username", "password"))

# What actually goes in the header (for reference):
credentials = base64.b64encode("user:pass".encode()).decode()
# → Authorization: Basic dXNlcjpwYXNz

OAuth 2.0 — The Full Flow

The standard for delegated authorization. Instead of sharing credentials, users grant permission to your app. Used by Google, GitHub, Twitter, etc.

def safe_api_call(url: str, **kwargs) -> dict:
    """Wrapper with complete error handling."""
    try:
        response = requests.get(url, timeout=10, **kwargs)
        response.raise_for_status()         # Raises on 4xx / 5xx
        return {"success": True, "data": response.json(),
                "status": response.status_code}

    except requests.exceptions.Timeout:
        return {"success": False, "error": "Request timed out after 10s"}

    except requests.exceptions.ConnectionError:
        return {"success": False, "error": "Network connection failed"}

    except requests.exceptions.HTTPError as e:
        return {"success": False, "error": str(e),
                "status": e.response.status_code}

    except requests.exceptions.JSONDecodeError:
        return {"success": False, "error": "Response was not valid JSON"}


# Using the safe wrapper:
result = safe_api_call("https://jsonplaceholder.typicode.com/posts/1")
if result["success"]:
    print(result["data"]["title"])
else:
    print(f"Error: {result['error']}")

Topic 06 · Politeness

⏱️ Rate Limits & Backoff

Rate limits protect API servers. Exceed them and you get 429 Too Many Requests. Every production client must implement exponential backoff and throttling.

Exponential Backoff — Wait times on consecutive failures
1s
Attempt 1
2s
Attempt 2
4s
Attempt 3
8s
Attempt 4
16s
Attempt 5
Wait = 2attempt + random(0, 1) seconds (jitter prevents thundering herd)
Python · 06_rate_limits.py — Exponential Backoff
import time, random

def exponential_backoff_request(url: str, max_retries: int = 5):
    """Retry with exponential backoff on 429 or 5xx errors."""
    for attempt in range(max_retries):
        try:
            response = requests.get(url, timeout=10)

            if response.status_code == 429:
                wait = response.headers.get("Retry-After", 2 ** attempt)
                print(f"  [429] Rate limited. Waiting {wait}s...")
                time.sleep(float(wait))
                continue

            if response.status_code >= 500:
                wait = (2 ** attempt) + random.uniform(0, 1)  # jitter
                time.sleep(wait)
                continue

            return response   # ✅ Success

        except requests.exceptions.ConnectionError:
            time.sleep(2 ** attempt)

    return None  # All retries exhausted


# Polite batch requests with delay between calls
def throttled_batch(post_ids, delay=0.3):
    results = []
    for pid in post_ids:
        r = requests.get(f"https://api.example.com/posts/{pid}")
        results.append(r.json())
        time.sleep(delay)   # ← polite delay between requests
    return results

Topic 08 · Best Practice

🔒 API Security

API key leaks can cause unauthorized charges, data breaches, and account suspension. These patterns are non-negotiable in production code.

🛡️ Security Checklist

✅
Use Environment Variables

Load keys from os.environ.get("MY_API_KEY"), never from source code.

✅
Use .env + python-dotenv

Store secrets in .env file, load with load_dotenv().

✅
Always Use HTTPS

Never set verify=False in production. TLS is not optional.

✅
Mask Sensitive Logs

Truncate/redact Authorization headers and API keys before logging.

❌
Never Hardcode Keys

Keys in source code = keys in git history = permanent security risk.

❌
Never Commit .env to Git

Add .env to .gitignore immediately. Use .env.example for templates.

Python · 08_security.py — The .env Pattern
# .env file (NEVER commit this to git!)
# MY_API_KEY=your_actual_key_here
# DATABASE_URL=postgresql://user:pass@localhost/db

from dotenv import load_dotenv
import os

load_dotenv()                              # Reads .env into os.environ
api_key = os.environ.get("MY_API_KEY")   # None if not set

if not api_key:
    raise EnvironmentError("MY_API_KEY is not set. Check your .env file.")

# Safe logging — mask sensitive values
def mask_key(key: str) -> str:
    return key[:4] + "*" * (len(key) - 4) if key else "NOT SET"

print(f"API Key: {mask_key(api_key)}")     # → API Key: sk-p****** (safe to log)

# Always validate HTTPS
response = requests.get(url, verify=True)  # Default — never set to False!

Python · 08_crud_application.py — Full CRUD
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI(title="Books CRUD API")
db: dict[int, dict] = {}  # In-memory store
next_id = 1

class Book(BaseModel):
    title: str; author: str; year: int; rating: float = 0.0

@app.post("/books", status_code=201)
def create(book: Book):
    global next_id
    db[next_id] = book.model_dump(); record = {"id": next_id, **db[next_id]}
    next_id += 1; return record

@app.get("/books/{book_id}")
def read(book_id: int):
    if book_id not in db: raise HTTPException(404, "Book not found")
    return {"id": book_id, **db[book_id]}

@app.put("/books/{book_id}")
def update(book_id: int, book: Book):
    if book_id not in db: raise HTTPException(404, "Book not found")
    db[book_id] = book.model_dump(); return {"id": book_id, **db[book_id]}

@app.delete("/books/{book_id}", status_code=204)
def delete(book_id: int):
    if book_id not in db: raise HTTPException(404, "Book not found")
    del db[book_id]
